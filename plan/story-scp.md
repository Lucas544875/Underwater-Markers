## 仮題：SCP-XXXX-JP 『溺れる報告書』

（別名案：『犠牲者はいなかった』『水位より下の記録』）

※ 番号 XXXX はプレースホルダ。SCP共有ユニバースの名義・様式を公開作品で用いる場合、SCP財団日本支部のライセンス（CC BY-SA 3.0）の継承が必要になる点に留意。様式だけ借りた独自の「財団風」組織名（例：記録保全機構）に差し替えれば、この制約は回避できる。

**実装ノート（scp-versionブランチ）**：上記の理由から、実装ではライセンス継承なしで公開できる独自名義を採用した。組織名は **記録保全機構**、オブジェクト指定は **YMS-1938**（夜見沢・1938年）。SCP名義に戻す場合は、固有名詞の置換（記録保全機構→SCP財団、YMS-1938→SCP-XXXX-JP、機構注記→財団注記）と、サイトへのCC BY-SA 3.0表記の追加のみでよい。

## 0. 方針 —— なぜSCP形式は本作の演出と噛み合うのか

新聞記事版（story-v2）では、「閲覧によって壊れるページ」を成立させるために、作中の新聞社が贖罪としてそういう仕様のページを**設計した**、という一段の迂回が必要だった（奥付での種明かし）。

SCP形式ではこの迂回が消える。**報告書自体がオブジェクトに汚染されている**なら、読むと壊れることは設計ではなく症状であり、ページの挙動すべてが文書の異常性の直接の描写になる。演出と物語の距離がゼロになる。

- 新聞版：ページが壊れる ＝ 誰かがそう作った（動機の説明が要る）
- SCP版：ページが壊れる ＝ 文書がそういう病気に罹っている（説明そのものが本文になる）

さらにSCP様式の定型（黒塗り、削除済み表記、版管理、閲覧権限、実験記録）は、本作がすでに持っている演出——メタデータの欠落、赤入れ、損傷の永続化——の完璧な受け皿になる。

「水にまつわる事件である」は維持する。舞台は夜見沢貯水池のまま流用できる。

## 1. 物語の核

**一文で:**

> 夜見沢貯水池についての**正確な記述は、読まれるたびに水に還る**。虚偽の記述だけが決して滲まない。したがって、この報告書のなかで今もはっきり読める文は——すべて嘘である。

**オブジェクトの基本法則（この5つがすべての演出の根拠になる）:**

| 法則 | 内容 | 対応する画面挙動 |
| --- | --- | --- |
| 1. 溺死則 | 夜見沢の事件に関する**正確な平叙文**は、読まれるたびに滲み、流れ、水に還る。劣化速度は「正確さ × 閲覧数」に比例する | スクロールで文節が流され、薄れ、二度と元の濃さに戻らない |
| 2. 浮力則 | **虚偽の記述は決して劣化しない。** 完全に鮮明なまま残り続ける | どれだけ操作しても崩れないテキストが存在する |
| 3. 命令則 | 命令文・疑問文・見出しなどの**真偽を主張しない文**は沈まない | ナビゲーション、警告文、ボタン、見出しが常に無傷である理由 |
| 4. 写像則 | 写真・図版は**何も主張しない**ため沈まない。ただし後年の転写時に朱書きされた校正記号は文であり、滲む | 写真が固定境界として歪まない理由／写真内の赤い線 |
| 5. 転移則 | 溺れた記述は消滅するのではなく、**読んだ者の記憶に移る**。記憶を文書に書き戻すと、その文は再び溺れ始める | 損傷の永続化。読者が「持ち出した」分だけ、次の閲覧者に残る本文は少ない |

この法則群により、「読むほど壊れる」「壊れない部分がある」「リロードしても戻らない」「写真だけ無事」「UIだけ無事」という本作の挙動全部に、一つの整合した作中理由が与えられる。

## 2. オブジェクトの起源（水にまつわる事件）

1938年、夜見沢ダム建設に伴い夜見沢村が水没した。公式記録には移転完了と記され、竣工報告書は一行でこう結んだ——**「犠牲者はいなかった。」**

実際には、立ち退きを拒んだ、あるいは通知が届かなかった村民が湛水時に村に残っていた。人数は記録されなかった。遺族の抗議文書は受理されず、唯一の実測記録だった駐在所の日誌は「紛失」した。真実は書類の上で溺死し、書類の上では誰も死ななかった。

異常性が始まったのはその直後である。**水を偽った書類の側に、水が入り込むようになった。** 夜見沢について正確に書かれたものは、読まれるたびに水損する。偽りの記述は、竣工報告書のあの一文と同じように、永遠に乾いたまま残る。

オブジェクトは水そのものではない。**「記録と水位の対応関係」**であり、収容も破壊もできない。財団（あるいは記録保全機構）にできるのは、文書の水位を管理することだけである。

## 3. 文書構成（全7文書＝既存の7記事スロットに対応）

読者はクリアランスを持つ職員として、割当制の閲覧枠を1回分消費してこのファイルを開いた、という体裁を取る。冒頭に表示される：**「この閲覧は記録されます。」**

### 文書1：特別収容プロトコル（表層・ほぼ無傷）

- ほとんどが命令文で書かれているため、ほぼ完全に読める。SCP報告書の収容手順が定型的に命令形で書かれることに、本作では明確な作中理由がある（命令則）。
- 内容：閲覧は申請制・一人一回。音読の禁止。本文の複製・転写の禁止（転写した瞬間、その複製も溺れ始めるため封じ込めにならない）。「本文書について他者に語る場合、不正確に語ること」——正確な口述は聞き手の記憶内で成立した時点で原文の劣化を加速させる。
- 最後の一行だけ平叙文で、わずかに滲んでいる：「本プロトコルは、オブジェクトを収容していない。」——正確だから滲む。読者への最初の无言のヒント。

### 文書2：説明（可読・所々が滲む）

- オブジェクト指定、発見経緯、基本法則1〜5の説明。法則の説明文のうち、よく読まれてきた段落ほど薄い（この文書内で既に法則が実演されている）。
- 夜見沢貯水池の写真を掲載。写真は完全に鮮明（写像則）。キャプションの一部だけが滲んでいる。

### 文書3：実験記録XXXX-α（法則の確立）

- 記述文を用いた対照実験のログ。表形式。
  - 「夜見沢貯水池は存在しない。」——**720日経過、劣化なし。**
  - 「夜見沢貯水池は山間部にある。」——閲覧40回で判読不能。
  - 「湛水は1938年に行われた。」——閲覧12回で判読不能。
  - 「湛水時、村には人が残っていた。」——**閲覧1回で判読不能。**
- 劣化速度は正確さと重大さに比例する。**最も速く溺れる文が、最も真実である。** 研究員は気づく——このオブジェクトは、劣化速度という形で「どれが真実か」を教えている。真実の内容は読めないのに、真実の在り処だけが分かる。
- 記録の末尾、対照群として置かれた一文：「犠牲者はいなかった。」——**観測開始以来、一切の劣化なし。** 起源への最初の接続。読者はここで胃が冷える。

### 文書4：補遺XXXX-1 起源調査（物語の底）

- 1938年の湛水、移転記録、竣工報告書の複写（写真として掲載——写像則により複写画像は無傷で、あの一文がはっきり写っている）。
- 犠牲者数の特定の試み：数字を書いた瞬間に滲む。本文中の該当箇所は「残存人数は[判読不能]名」の連続。**数字だけが何度書いても溺れる＝その数字が正しいことの証明**だが、値は永遠に読めない。
- 村民名簿の復元の試み：氏名の列がすべて水紋状に滲んだ表。一名も読めない。読める名前が一つだけある——移転完了を報告した当時の役人の名。**書類の上で生き残るのは、いつも加害者の名前である。**

### 文書5：文書運用規則（冷たい壁・様式の頂点）

- 事務文書。黒塗りと欠落が最も濃い（既存演出のメタデータ欠落をこの文書に集中させる）。
- 明かされる運用の核心：**本文書は虚偽の混入によって浮いている。**
  - 溺死則により、完全に正確な報告書は保存不可能である。
  - よって各版の改訂時、規定割合の虚偽を意図的に混入する。虚偽は劣化しないため、文書の骨格として残り、読者に「読める文書」を提供し続ける。
  - **混入箇所および混入率は記録しない。**（虚偽の位置を正確に記録した文書は、正確であるがゆえに溺れるため、原理的に管理できない）
  - 本文書は第9版である。第1版〜第8版は判読不能。各版は、前版を読んだ職員の記憶による再構成である。
- つまり読者がここまで読んできた全文書について、**どこまでが本当か、財団自身にも分からない。** 転写を重ねた文書の文節が本来の位置に戻りきらない（粒子演出）のは、9回の記憶越しの再構成のずれそのものである。

### 文書6：インタビュー記録XXXX-7（感情の爆発点）

- 対象：記憶担当職員・時任凪（ときとう・なぎ、63）。歴代で最も多く本文書を読んだ人物。第6版〜第9版の再構成の主担当。
- 骨子：
  - 「読むたびに、私の好きだった段落から死んでいきました。正確に書けた段落から、順番に。自分の仕事が上手くいったかどうかを、文の死亡速度で知るんです」
  - 村民名簿について：「第6版までは、まだ三人ぶん読めたんです。私は覚えました。覚えて、確かめるために読み返して——読み返した回数だけ、名簿は薄くなりました。**確かめることと、消すことが、同じ行為でした。**」
  - 現在、三人の名を諳んじられるのは彼女だけである。しかし転移則により、彼女がその名を書き戻せば名は再び溺れ、口述すれば聞き手の記憶内での成立と引き換えに劣化が進む。**彼女の記憶は、検証した瞬間に破壊が始まる、検証不能な最後の一次資料である。**
  - 「私が死んだら、あの三人は二度目の水葬になります。それでも私は、後任に名前を教えません。教えたら減るからです。……いいえ。本当は、減るからじゃない。**減らすのが私でなくなるのが、耐えられないんです。**」
- インタビュアーの最後の所見一行：「対象の証言の正確性は、評価できない。評価に成功した場合、証言は失われる。」

### 文書7：付録XXXX-B 残存断片（最終文書・読者の選択）

- 1938年の一次資料の現存断片5点（駐在所日誌の切れ端、抗議文書の封筒、湛水前日の乗車券、など）。
- **各断片は一度しか読めない。** 開いた瞬間から滲み始め、数秒で判読不能になり、その状態が永続化される（既存の損傷永続化機能の最終利用形態）。5枚すべてを読むことも、読まずに残すこともできる。
  - 読めば、内容はあなたの記憶にだけ残る（転移則）。
  - 読まなければ、内容は保存されるが、誰の記憶にも入らない。
- 既存の証拠パズル（ドラッグ・閲覧検知）をそのまま流用できる。「動かす／調べる」を「読む＝殺す」に置き換えるだけでよい。
- 全断片の操作後、終幕へ。

### 終幕

画面から溺れた本文がすべて退き、鮮明なテキストだけが残る。読者は法則2を知っているので、説明は要らない——**残っているものが、嘘である。**

中央に、一切滲みのない、印刷したての一文。

> 犠牲者はいなかった。

沈黙ののち、最下部に最後の一文が浮かぶ。これも完全に鮮明なまま。

> 本文書に、虚偽は含まれていません。

読者は自分で規則を適用してしまう。鮮明である＝劣化していない＝……。文書は、嘘についてさえ嘘をつく。どの層の嘘なのかは、原理的に確かめられない。

最後に閲覧カウンタが一つ増える。

> 閲覧記録：あなたは本文書の第9版を閲覧した4,116人目です。
> あなたの閲覧により、本文書の残存率は0.02%低下しました。
> 次の閲覧者に残る本文は、あなたが読んだものより少ない。

## 4. 反転の設計

| 位置 | 反転 | 読者の認識の書き換わり |
| --- | --- | --- |
| 文書3 | 法則の意味の反転 | 劣化は損失ではなく**真実の位置を示す唯一の計器**だった。「読めない箇所」の意味が全文書で反転する |
| 文書4〜5 | 文書自身への反転 | 「犠牲者はいなかった」が不滅の理由が起源と接続し、直後に「この報告書自体が嘘で浮いている」と明かされる。既読の全文が疑わしくなる |
| 文書6 | 人間への転移 | 記録の問題が一人の人間の記憶と尊厳の問題に収斂する。「確かめることと消すことが同じ」という法則が、感情の言葉になる |
| 文書7〜終幕 | 読者への回帰 | 読む／読まないの選択が読者自身に手渡され、最後に「鮮明さ＝虚偽」の規則が読者の目の前の画面全体に適用される |

## 5. 因果の検証（necessity audit）

| 問い | 答え |
| --- | --- |
| なぜページは閲覧で壊れるのか | オブジェクトの溺死則そのもの。演出ではなく症状。説明の迂回（新聞版の「設計された追悼装置」）が不要 |
| なぜ壊れないテキストがあるのか | 浮力則（虚偽）と命令則（真偽を主張しない文）。UIや見出しが無傷なことに作中理由がある |
| なぜ写真は歪まないのか | 写像則。画像は主張しないため沈まない。既存実装の「写真＝固定境界」と完全一致 |
| なぜ損傷はリロードしても戻らないのか | 転移則。読まれた分は読者の記憶に移っており、文書には戻らない。閲覧カウンタが根拠を可視化する |
| なぜ財団は文書を破棄しないのか | 破棄は村民の二度目の抹消になる。ゆっくり溺れる記録と、即座の完全な忘却の二択で、前者を選び続けている（倫理委員会裁定として文書5に一行残す） |
| なぜ虚偽を混入するのか | 正確な文書は保存不可能。嘘だけが浮力を持つ。読める文書を維持する唯一の方法が、信頼できない文書にすることだった |
| なぜ真相（犠牲者数・名簿）は最後まで出ないのか | 出せないことが法則の帰結であり、かつ主題。最も正確な情報は最速で溺れるため、原理的に文書内に存在できない。唯一の保管場所が検証不能な人間の記憶（時任）である |
| 読者の加害性はどこにあるのか | 冒頭で「この閲覧は記録されます」と警告された上で読み進める。断片5点では「読む＝永久破壊」を明示的に選択させる。読了自体が残存率を削る |

## 6. 既存実装との対応

コード側の主要機構は、意味の付け替えだけでほぼ流用できる。

| 既存機構 | 新聞版での意味 | SCP版での意味 |
| --- | --- | --- |
| 文節粒子の流失・非復元 | 版の揺らぎ | 溺死則。正確な文から水に還る。9版分の転写ずれ |
| 崩れないUI・見出し | （理由なし＝作品外の都合） | **命令則。真偽を主張しない文は沈まない** |
| 写真の固定境界 | 報道写真の保全 | 写像則。画像は主張しない |
| 赤い染料・写真内の赤線 | 校閲の赤字 | 歴代転写時の朱書き校正（文であるため滲む） |
| メタデータ黒塗り（第5スロット集中） | 保存期間切れ | 検閲＋水損。文書運用規則に集中 |
| 損傷の永続化 | 追悼装置の仕様 | 転移則＋閲覧カウンタ |
| 証拠パズル（5断片） | 時系列の再構成 | **一度しか読めない断片。読む＝殺すの明示的選択** |
| 終幕の奥付→第1記事回帰 | 更新時刻の再発見 | 「犠牲者はいなかった。」→「本文書に、虚偽は含まれていません。」 |
| 深度による劣化の進行 | 記事の深層ほど崩れる | 文書の並び順を「正確さの昇順」と定義する——深い文書ほど真実に近く、ゆえに溺れている |

最後の行は追加の発明：**7文書の並び順そのものに意味がある。** 表層が読みやすいのは安全だからではなく、真実から遠いからである。

## 7. 新聞版との使い分け

- **新聞版（story-v2）**：現実の地続きの恐怖。因果は完全に非超常で、加害者は善意の人間。読後感は「これは実際に起こり得る」。
- **SCP版（本案）**：演出との一体性が最強。ページの挙動すべてが本文になる代わりに、超常の公理を一つ飲ませる。読後感は「読めないことが、読める」。

共通の芯は同じ——**記録は見られた順に死に、生き残った記録は信用できない。そして読者は、警告された上で、読むことを選んだ。**

新聞版の「更新 19時47分」に対応する本案の刃は、「鮮明さ」そのもの。前者は読み飛ばした一行を突きつけ、後者は**いま読めているという事実**を突きつける。
