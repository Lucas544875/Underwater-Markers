# 老人と海

スクロールとカーソルの動きに応じて文章がたゆたう、一枚ページのインタラクティブな読書体験です。画像は使わず、文章そのものと、周囲の空(海)の色調の変化だけで、三日二晩の時間経過を表現します。

本文は、[青空文庫](https://www.aozora.gr.jp/cards/001847/card57347.html)収録の石波杏訳『老人と海』（アーネスト・ヘミングウェイ *THE OLD MAN AND THE SEA*, Jonathan Cape, 1952／2015年7月翻訳公開）を、[クリエイティブ・コモンズ 表示 2.1 日本 (CC BY 2.1 JP)](https://creativecommons.org/licenses/by/2.1/jp/) ライセンスのもとで使用しています。ルビ（読み仮名）は省略し、訳者あとがき・参考文献一覧はこのページには含めていません。原作（英語版）自体の著作権は日本国内では2031年まで存続していますが、この日本語訳は翻訳者自身の意思により上記ライセンスで公開されています。

章立て（全13場面の見出しと場面ごとの演出強度）は、この作品を独自に構成したものです。

```bash
npm install
npm run dev
```

本番用の静的ファイルは `npm run build` で `dist/` に生成されます。
