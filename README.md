# 老人と海｜潮の記憶

カーソル移動とスクロールが低解像度の流体場を動かし、画面内の文節が潮流を受けて漂う読書サイトです。

```bash
npm install
npm run dev
```

本番用ファイルは `npm run build` で `dist/` に生成されます。

## テキストとライセンス

本文は、アーネスト・ヘミングウェイ著『老人と海』石波杏訳（青空文庫 No.57347）を使用しています。翻訳文は [クリエイティブ・コモンズ 表示 2.1 日本](https://creativecommons.org/licenses/by/2.1/jp/) で提供されています。

- 原典: Ernest Hemingway (1952), *THE OLD MAN AND THE SEA*, Jonathan Cape.
- 翻訳・公開: 石波杏（2015年7月1日公開、同年9月29日最終更新）
- 収録元: [青空文庫の作品ファイル](https://www.aozora.gr.jp/cards/001847/files/57347_57224.html)
- 本サイトでは、元のテキストから本文以外の部分を削除し、本文を数文字程度のオブジェクト単位に分割して動的に配置しています。翻訳内容そのものの改変は行っていません。

## 負荷対策

本文は段落が表示領域へ近づいた時だけ遅延分節化されます。`IntersectionObserver` と個別文節の画面座標判定による二段階カリングを行い、画面外の文節は物理計算から除外します。流体場も画面サイズに合わせた42pxグリッド、約32fpsで更新します。
